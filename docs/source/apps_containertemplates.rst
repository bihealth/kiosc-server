Container Templates
===================

Container templates were conceived to facilitate the creation of containers
by offering default settings that can be copied during the creation of an
actual container. Container templates themselves can be duplicated and copied
to different projects. They do exist as a project-wide for every user, and
as site-wide only available for the administrators. In a fresh installation,
one site-wide container template is already available. This can give the
users a jump start, act as a teaser to motivate the user to create their own
containers and also be a smoke test whether the installation worked. The
predefined template is a demo of a Shiny app taken from the `Rocker project
<https://rocker-project.org/images/versioned/shiny.html>`__.
